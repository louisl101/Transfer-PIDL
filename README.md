# Transfer-PIDL Model 
### Large-scale Pre-training & Physics-guided domain adaptation & Local Site-specific Fine-tuning 

> **Note:** This project only provides essential source code of the Transfer-PIDL model for paper submission
> **Note:** The full running scripts will be updated after acceptance

### Environment Dependencies

- **Python 3.6 or above**

#### Standard Python Libraries (built-in)

- `json`
- `os`
- `subprocess`
- `sys`
- `argparse`
- `warnings`
- `multiprocessing`
- `logging`

#### Additional Third-party Libraries

- `torch` (PyTorch framework for deep learning)
- `numpy` (Numerical computations)
- `pandas` (Data handling and analysis)
- `tqdm` (Progress bar display)
- `pyfiglet` (Banner display in terminal)

#### Installation

You can install all required third-party dependencies using `pip`:

```bash
pip install torch numpy pandas tqdm pyfiglet
```
